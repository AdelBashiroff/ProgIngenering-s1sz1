# Единый отчёт

Баширов Адель Тагирович, КФУ, ИТИС, группа 11-411.

- [Отчёт PDF, 12 страниц](Report_Bashirov_11-411.pdf)
- [Редактируемый DOCX](Report_Bashirov_11-411.docx)

В отчёте объединены текст, аудио, Images, видео, локальная LLM, FastAPI,
автотесты и RecSys. Числа взяты из сохранённых результатов экспериментов.
Ранее полученные результаты отделены от повторных проверок запуска.
Все 12 страниц проверены после преобразования DOCX в PDF.
На титульном листе в нижнем колонтитуле стоит «Казань 2026», номер скрыт.
Титульный лист учитывается в общем счёте: следующая страница имеет номер 2.

## Повторная сборка

Из корня репозитория:

```bash
python -m pip install python-docx Pillow
python report/build_report.py
```

Скрипт читает файлы результатов модулей и создаёт DOCX. Для получения PDF
откройте DOCX в Word или LibreOffice и экспортируйте в PDF. После экспорта
проверьте переносы таблиц и иллюстраций: они зависят от версии редактора и шрифтов.

Полнота сверки с исходными заданиями описана в
[requirements-audit.md](../verification/requirements-audit.md).
