# Сравнение методов

Compare запрашивает item-CF и обученный LightGCN для одного пользователя.
Инструмент объединяет фильмы по сумме рангов и сохраняет оба исходных ранга.
Эти числа объясняют расхождение алгоритмов, но не являются вероятностями.
Нельзя объявлять GNN лучшей только потому, что она нейросетевая. Для сравнения
качества используются метрики отдельного эксперимента на всём test-наборе.
