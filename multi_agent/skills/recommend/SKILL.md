# Рекомендация

Применяется при просьбе выбрать фильмы. Планировщик выбирает recommend и метод.
Tool исключает все фильмы из train-истории, включая низкие оценки. Для нового
пользователя метод использует популярность, персонализация не обещается.
Жанры фильтруются по каталогу, запреты пользователя имеют приоритет над любимыми
жанрами. Автор объясняет выбор жанром или местом в выдаче, без пересказа сюжета.
Пустой результат означает, что под заданные ограничения подходящих записей нет.
