# История и каталог

History показывает только train-историю связанного с запуском пользователя.
Search ищет подстроку названия в локальном u.item. Поиск не подтверждает наличие
фильма в онлайн-кинотеатре. Автор выбирает только ID из ответа инструмента.
Оценки из отложенного test не используются как память о пользователе.
