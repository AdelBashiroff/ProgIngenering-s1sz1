# Архитектурные схемы

В C4 четыре статических уровня и три вспомогательных вида схем. Здесь используются
все семь видов из [официального списка](https://c4model.com/diagrams), а отдельно
добавлена sequence-диаграмма. В Mermaid сохранены редактируемые исходники. Названия
ролей, классов и переходы соответствуют `multi_agent/`, а не условному агенту.

| Файл | Вид C4 | Что показывает |
|---|---|---|
| [01-landscape.mmd](01-landscape.mmd) | System landscape | Помощник, RecSys, инференс, оценка, источники весов и данных |
| [02-context.mmd](02-context.mmd) | System context | Пользователи, граница системы, каталог и локальный инференс |
| [03-container.mmd](03-container.mmd) | Containers | Python-процесс, llama-server, SQLite и файлы наблюдения |
| [04-component.mmd](04-component.mmd) | Components | Узлы единого графа и модули памяти, tools, routing и наблюдения |
| [05-code.mmd](05-code.mmd) | Code | Фактические классы, схемы и зависимости |
| [06-dynamic.mmd](06-dynamic.mmd) | Dynamic | Порядок действий, кеш и ограниченная доработка |
| [07-deployment.mmd](07-deployment.mmd) | Deployment | Mac, Seatbelt, дочерний инференс, права файлов и сети |
| [08-sequence.mmd](08-sequence.mmd) | Дополнительная sequence | Обмен сообщениями, ветки проверки и сохранение результата |

`Container` в C4 означает исполняемую часть приложения или хранилище данных.
Он не означает, что здесь обязательно применяется Docker. Семь видов схем —
требование задания; сам C4 не требует рисовать все семь для каждого проекта.

Все три LLM доступны через один ModelRouter. В каждый момент запущен один
дочерний `llama-server`, модель меняется по роли. Планировщик и автор используют
семейство Qwen, проверяющий — SmolLM. Проверяющий не заменяет проверки схемы,
идентификаторов и повторов. После первой неудачной проверки разрешена одна
доработка автора, после второй ответ отклоняется.

Seatbelt ограничивает процесс и его потомков средствами macOS; это не отдельная
виртуальная машина. `sandbox-exec` помечен Apple как deprecated. Для отчёта нужно
ссылаться на реальные результаты probes и не делать по схеме вывод об устойчивости
к любому побегу из sandbox. Веса и исходные данные загружаются до изолированного
запуска, поэтому подключение к Hugging Face и GroupLens на landscape показано
пунктиром.

Диаграммы не обещают crash-resume: state графа находится в RAM, а таблица `runs`
сохраняет метаданные. Траектория позволяет разобрать произошедшее, но сама по себе
не является checkpoint для продолжения с прерванного шага.
