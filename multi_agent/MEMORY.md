# Правила памяти

В рамках запуска LangGraph хранит план, доказательства, черновик и замечания.
После ответа это рабочее состояние освобождается. Сводка исхода хранится 7 дней.

SQLite хранит результаты инструментов 1 час. Ключ включает SHA256 данных и
checkpoint, пользователя, план и версию явных предпочтений. После изменения
предпочтений кеш очищается. Изменение файла данных требует перезапуска процесса:
загруженная модель и версия каталога создаются вместе.

Долгая память содержит только жанры, которые пользователь явно записал командой
profile. У записи есть время обновления, версия и срок 30 дней. Истечение срока
не продлевается при чтении. Новая команда заменяет запись целиком. Команда forget
удаляет профиль и сводки запусков пользователя. Текст LLM ничего сюда не пишет.

Диагностические траектории отделены от памяти. Их очистка задаётся командой
monitor --retention-days. Локальная учебная версия не поддерживает несколько
аккаунтов и аутентификацию; ей нельзя давать публичный сетевой доступ.
