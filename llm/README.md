# Дополнение к части 1 — локальная LLM

Развёрнута [Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct),
открытая инструкциям обученная языковая модель (0,49 млрд параметров, Apache-2.0).
Компактный размер выбран для локального запуска на ноутбуке вместе с остальными задачами.
Облачный API и ключи не нужны. Поддерживаются CPU, Apple MPS и CUDA.

```bash
python -m llm.generate 'Объясни в трёх предложениях, зачем нужны автоматические тесты API.' \
  --max-new-tokens 160 --output llm/results/example.json
```

Установка: корневой `requirements.txt`. При первом запуске загружается около 1 ГБ весов.
В скрипте используется float32; фактическая память выше размера скачанных весов.
Вход ограничен 2048 токенами, генерация — максимум 512 новыми токенами.
Используются chat template модели, `do_sample=False` и режим без градиентов.
`results/example.json` содержит неизменённый реальный ответ, устройство и замеры скорости.

Это демонстрация локального развёртывания, а не полноценный бенчмарк LLM.
Небольшая модель может ошибаться, повторяться и нарушать требуемый формат;
качество русского ответа проверяется вручную. Код модели не выполняет сгенерированный текст.
Для более сложных задач возможна модель большего размера или квантование;
эти варианты здесь не оценивались.
