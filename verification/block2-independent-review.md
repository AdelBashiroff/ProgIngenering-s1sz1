# Проверка результатов LightGCN

Дата: 17 ноября 2026 года. Проверка выполнена чтением исходников и отдельным
пересчётом по сохранённому checkpoint. Исходники и результаты обучения при этой
проверке не изменялись; повторного подбора параметров по test не было.

## LightGCN и данные

- Пары `(user_id, item_id)` outer train и test не пересекаются; inner fit и
  validation также не пересекаются.
- Граф восстановлен из положительных оценок только outer train. Его индексы и
  веса точно совпали с `graph` в `state_dict` checkpoint.
- Нормализация: симметричная `D^(-1/2) A D^(-1/2)`, рёбра в обе стороны,
  без self-loops. Представление — среднее начального embedding и всех слоёв.
- В BPR используется `softplus(s_negative - s_positive)` и L2 исходных sampled
  embeddings. Negative sampling исключает все оценённые train-фильмы, включая
  оценки ниже четырёх.
- Модель восстановлена из `state_dict`; пересчитанные user/item embeddings
  совпали с сохранёнными представлениями.
- `seen` совпал со всеми outer-train событиями, а не только положительными.
- Для каждого из 915 оцениваемых пользователей проверены 10 уникальных ID и
  отсутствие любого train-seen фильма в выдаче.
- Для неизвестного пользователя 99999 выдача точно совпала с popular baseline.

## Повторный расчёт метрик

Из загруженного `lightgcn.pth` независимо получены рекомендации всех 915
пользователей и заново рассчитаны метрики. Расхождение с сохранённым
`recsys/results/advanced/comparison.csv` для каждой метрики меньше `1e-12`.

| Метрика | Повторный расчёт |
|---|---:|
| Precision@10 | 0.13300546448087433 |
| Recall@10 | 0.13514423081662802 |
| NDCG@10 | 0.16640779135322975 |
| MAP@10 | 0.09016389828548299 |
| Hit Rate@10 | 0.5879781420765028 |

Глубина графа и эпоха выбирались на inner validation; затем модель заново обучена
на полном outer train. В коде подбора test не используется.

## Границы вывода

Разбиение временное внутри каждого пользователя, а не по одному общему моменту.
Событие другого пользователя в train может быть позднее оцениваемого события.
Поэтому результат описывает выбранный per-user holdout и не доказывает качество
прогноза будущего относительно глобальной даты. Полный каталог известен заранее;
метаданные холодных фильмов доступны, а test-оценки в обучающий граф не входят.

Разность NDCG LightGCN и item-CF равна 0.0013470908227552704. Парный bootstrap
95% интервал `[-0.00891241262375023; 0.010702858224905716]` включает ноль.
Уверенная победа над item-CF этим экспериментом не подтверждается.

Проверка не является повторным исследованием на новых данных и не доказывает
рост CTR или удержания. Результат одного seed на MovieLens 100K нельзя без
дополнительного эксперимента переносить на современный сервис.
