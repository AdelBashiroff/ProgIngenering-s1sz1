Список тулов для организации памяти
Graphiti – фреймворк для построения темпоральных графов знаний для памяти агентов с инкрементальным обновлением, гибридным retrieval. Ориентирован на production и замену классического RAG
25.1k ⭐️
https://github.com/getzep/graphiti 
PageIndex – система RAG без использования векторных баз данных, основанная на рассуждениях. Строит иерархическое древо (оглавление) документа и использует LLM для навигации по нему в процессе поиска, имитируя то, как человек извлекает знания из сложных документов.
25.5k ⭐️
https://github.com/VectifyAI/PageIndex 
SuperMemory – платформа для создания персональной базы знаний, собираемой из разрозненных источников. Предоставляет API для работы с памятью, позволяя агентам сохранять и извлекать информацию из различных потоков контента, обеспечивая целостный контекст для взаимодействий.
22k ⭐️
https://github.com/supermemoryai/supermemory 
Cognee – опенсорсный движок для построения динамической памяти AI-агентов. Позволяет загружать данные в любом формате и непрерывно обучается, чтобы предоставлять агенту релевантный контекст. Объединяет векторный поиск, графовые базы данных и подходы когнитивной науки для связывания информации по смыслу и отношениям.
16.4k ⭐️
https://github.com/topoteretes/cognee 
Letta (ранее MemGPT) – платформа для создания агентов с внутренним состоянием и продвинутой памятью. Позволяет агентам обучаться и самостоятельно улучшаться с течением времени, редактируя собственные блоки памяти. Включает фреймворк для запуска агентов локально и API для интеграции в приложения.
22.1k ⭐️
https://github.com/letta-ai/letta 
Rowboat – опенсорсный AI-ассистент, который подключается к вашей почте и заметкам о встречах, строит из них долгоживущий граф знаний и использует этот контекст для помощи в работе. Все данные хранятся локально в виде Markdown-файлов, совместимых с Obsidian, что обеспечивает приватность и прозрачность.
12.8k ⭐️
https://github.com/rowboatlabs/rowboat 
LangMem – инструмент от LangChain, помогающий агентам обучаться и адаптироваться на основе взаимодействий. Предоставляет примитивы для извлечения важной информации из диалогов, оптимизации поведения агента через уточнение промптов и поддержания долговременной памяти с нативной интеграцией в хранилище LangGraph.
1.4k ⭐️
https://github.com/langchain-ai/langmem 
memU – фреймворк памяти, разработанный специально для проактивных агентов, работающих в режиме 24/7. Представляет память как файловую систему, обеспечивает структурированный и иерархический доступ к знаниям. Значительно снижает затраты на токены LLM при длительной работе агента.
13.4k ⭐️
https://github.com/NevaMind-AI/memU 
Mem0 – универсальный слой памяти для AI-агентов, обеспечивающий персонализированные взаимодействия за счет запоминания пользовательских предпочтений и адаптации к индивидуальным потребностям. Поддерживает многоуровневую память (пользователь, сессия, агент) и предлагает как облачный, так и самостоятельно развертываемый варианты использования.
53.4k ⭐️
https://github.com/mem0ai/mem0 
LlamaIndex – data framework для построения LLM-приложений с акцентом на ingestion, индексацию и retrieval. Предоставляет коннекторы к источникам данных (API, PDF, SQL), различные структуры (векторные индексы, графы), а также гибкие query engine и retriever’ы. Поддерживает 300+ интеграций (LLM, embeddings, vector DB) и позволяет строить кастомные RAG/agent pipelines с тонкой настройкой. Часто используется как “middleware” между данными и LLM.
48.7k ⭐️
https://github.com/run-llama/llama_index 
Zep – специализированное хранилище памяти для AI-агентов. Хранит историю диалогов, извлекает факты, делает summarization и обеспечивает semantic retrieval по памяти пользователя. Часто используется как drop-in memory layer.
4.5k ⭐️
https://github.com/getzep/zep 
RAGFlow - RAG-движок с упором на глубокое понимание документов. Объединяет retrieval, агентные workflow и ingestion в единый контекстный слой, поддерживает мультимодальные данные и explainable citations, снижая hallucinations и упрощая построение enterprise-grade AI-систем.
78.6k ⭐️
https://github.com/infiniflow/ragflow
